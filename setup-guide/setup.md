# ⚡ Quick VS Code Setup Guide

Follow these simple steps to restore your complete development environment in less than 2 minutes.

---

### 1️⃣ Step 1: Install VS Code & Tools
Install **Visual Studio Code** along with essential runtimes.
- 🌐 **Download**: [code.visualstudio.com](https://code.visualstudio.com/)
- 📦 **Prerequisites List**: [apps-used-for-vscode.md](https://github.com/Shariar-Ahamed/Visual-Studio-Code-Customization/blob/main/setup-guide/apps-used-for-vscode.md)

---

### 2️⃣ Step 2: Open Settings (JSON)
1. Open VS Code.
2. Press `Ctrl + Shift + P` (or `Cmd + Shift + P` on Mac).
3. Search and select: **`Preferences: Open User Settings (JSON)`**.

---

### 3️⃣ Step 3: Apply Settings
Copy and paste your preferred settings into the file:
- ⚡ **Minimal Setup (Fast & Clean)**: [settings.min.json](https://github.com/Shariar-Ahamed/Visual-Studio-Code-Customization/blob/main/settings/settings.min.json)
- 🛠️ **Full Setup (Advanced)**: [settings.json](https://github.com/Shariar-Ahamed/Visual-Studio-Code-Customization/blob/main/settings/settings.json)

---

### 4️⃣ Step 4: Install Extensions
Install the required extensions for Frontend & React development:
- 🔌 **Curated Extension List**: [extensions-list.md](https://github.com/Shariar-Ahamed/Visual-Studio-Code-Customization/blob/main/extensions/extensions-list.md)

---

### 5️⃣ Step 5: Restart & Enjoy!
Press `Ctrl + Shift + P` → select **`Developer: Reload Window`** (or restart VS Code).
