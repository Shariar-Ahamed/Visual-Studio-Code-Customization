<h2 align="center">Keyboard Shortcuts</h2>

<p align="center">
This directory contains the official default keyboard shortcut reference guides for Visual Studio Code. 
These shortcuts are not customized — they are the standard keybindings provided by VS Code.
</p>

<p align="center">
Keyboard shortcuts significantly improve productivity by reducing dependency on the mouse 
and enabling faster navigation, editing, debugging, and workflow control.
</p>

<hr>

### About This Section
Visual Studio Code provides printable PDF references of its default keyboard shortcuts for each supported operating system.  

You can access the shortcut reference directly from VS Code:  

> **Help → Keyboard Shortcut Reference**

This opens a condensed and printable PDF version suitable for quick reference.

---

### Platform-Specific Shortcut References  

The platform-specific PDF files are stored inside this directory for quick access:

 - [Windows](https://code.visualstudio.com/shortcuts/keyboard-shortcuts-windows.pdf)
 - [macOS](https://code.visualstudio.com/shortcuts/keyboard-shortcuts-macos.pdf)
 - [Linux](https://code.visualstudio.com/shortcuts/keyboard-shortcuts-linux.pdf)

---

### Important Notes  
- These are the **default keybindings** provided by Visual Studio Code.  
- No custom `keybindings.json` file is included in this repository.  
- Shortcuts may vary slightly depending on keyboard layout and system configuration.  
- Users can customize shortcuts from:

```bash
File → Preferences → Keyboard Shortcuts
```  
or by editing:  
```bash
keybindings.json
```
